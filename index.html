Backup e segurança

Os dados ficam somente no armazenamento deste navegador/dispositivo. Limpar o navegador ou perder o celular pode apagá-los. Faça backups periódicos. Para uso por várias pessoas, será necessário um banco de dados corporativo com controle de acesso.

Lote: Tesseract.js local. Manuscrito: PaddleOCR.js (PP-OCRv6) de código aberto, com processamento no navegador após download inicial. As dependências e o modelo são baixados de servidores públicos, portanto podem revelar metadados de acesso; o aplicativo não envia intencionalmente as fotos a eles. Para implantação empresarial, hospede as dependências internamente e faça auditoria de rede.
